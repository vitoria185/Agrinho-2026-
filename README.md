# Agrinho 2026

Landing page de apresentação para o Agrinho 2026, com foco em público agro e conteúdo técnico.

## O que está incluído

- `index.html` — página principal com banner, quem somos, produtos, inovação, notícias, depoimentos e contato.
- `style.css` — estilos responsivos, padrão mobile-first e visual inspirado em terra, natureza e tecnologia.

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Edite textos, contatos e links conforme sua empresa.
3. Substitua os links de PDF e o número do WhatsApp pelos dados reais.
